<p class="guide-lead">Этот материал продолжает базовый гайд по WorldEdit. Здесь собраны команды для сложных построек: геометрические фигуры, сохранение схем, выборочная вставка, изменение биомов и логические условия.</p>

<div class="guide-note">
  <strong>Перед началом</strong>
  <p>Нужно уверенно пользоваться выделением, буфером обмена, <code>//undo</code> и <code>//paste</code>. Если эти команды пока выглядят как заклинания, сначала открой <a href="/guides/worldedit-basics/">основы WorldEdit</a>.</p>
</div>

## Вращение, отражение и текст

Операции выполняются над содержимым буфера обмена. Сначала выдели постройку и скопируй её через `//copy`.

```text
//flip <x|y>
//rotate <90|180|270>
```

- `//flip x` отражает буфер по горизонтали;
- `//flip y` отражает по вертикали;
- `//rotate 90` поворачивает координаты тайлов на 90 градусов.

После преобразования вставь результат через `//paste`.

<div class="guide-warning">
  <strong>Ограничение Terraria</strong>
  <p>Поворот и отражение меняют расположение тайлов, но не всегда разворачивают сам спрайт предмета. Мебель, статуи и другие сложные объекты после поворота могут выглядеть неправильно.</p>
</div>

Команда для текста из буквенных статуй:

```text
//text <текст>
```

Поддерживаются латинские буквы `A–Z` и цифры `0–9`. Выделяй область с запасом.

## Геометрические фигуры

```text
//shape <тайл> <фигура> [поворот] [ориентация]
```

Базовая команда создаёт полую фигуру.

| Код | Фигура |
|---|---|
| `r` | прямоугольник |
| `e` | эллипс |
| `it` | равнобедренный треугольник |
| `rt` | прямоугольный треугольник |
| `l` | линия от первой точки до второй |

Примеры:

```text
//shape 1 it d
//shape 1 rt l d
//shape 2 rt r u
```

Разновидности команды:

```text
//shapefill     — цельная фигура из тайлов
//shapewall     — полая фигура из стен
//shapefillwall — цельная фигура из стен
```

Для треугольников используются направления `l`, `r`, `u`, `d`. Для прямоугольника и эллипса дополнительные направления не нужны.

## Специальная вставка

```text
//spaste [точка привязки] [флаги]
//sp [точка привязки] [флаги]
```

Команда вставляет буфер, исключая отдельные типы данных.

| Флаг | Что не вставлять |
|---|---|
| `-t` | тайлы |
| `-w` | стены |
| `-et` | пустые тайлы |
| `-tp` | краску тайлов |
| `-wp` | краску стен |
| `-l` | жидкости |
| `-wi` | провода |

Примеры:

```text
//sp br -t
//sp -w -et -l
```

Первая команда вставляет содержимое от правого нижнего угла без тайлов. Вторая исключает стены, пустые клетки и жидкости.

## Схемы построек

Схема хранится на сервере и переживает очистку буфера. Это удобно для повторного использования построек и переноса между вайпами.

### Сохранить содержимое буфера

```text
//sc s <имя>
```

Перед сохранением выполни `//copy` или `//cut`.

### Скопировать выделение и сразу сохранить

```text
//sc cs <имя>
```

### Загрузить свою схему в буфер

```text
//sc l <имя>
```

### Посмотреть список

```text
//sc list [страница]
//sc !list [страница]
```

Первая команда показывает свои схемы, вторая — все схемы сервера, если хватает прав.

### Загрузить или вставить общую схему

```text
//sc !l <имя>
//sc !paste <имя> [точка привязки] [флаги]
```

`//sc !paste` вставляет схему непосредственно в точку `//p1`, минуя обычный буфер и команду `//paste`.

### Удалить схему

```text
//sc !del -confirm <имя>
```

<div class="guide-warning">
  <strong>Удаление необратимо</strong>
  <p>Перед подтверждением проверь точное имя. У сервера нет обязанности угадывать, что ты хотел удалить что-то другое.</p>
</div>

### Проверить размер

```text
//size c [имя игрока]
//size sc <имя схемы>
```

`c` проверяет буфер, `sc` — сохранённую схему.

## Режим указателя и масштабирование

```text
//wandmode
//wand
```

Режим указателя позволяет выбирать территорию Великим планом без постоянного ввода `//p1` и `//p2`. В исходном руководстве переключение описано через режим кусачек Великого плана: одиночное нажатие по пустому блоку приостанавливает режим, двойное включает обратно.

Изменение масштаба буфера:

```text
//scale + 5
//scale - 2
```

Масштабирование сложных объектов может давать артефакты, поэтому сначала проверь результат на копии и держи `//undo` под рукой.

## Контуры

```text
//outline <тайл> <краска> <положение>
//ol <тайл> <краска> <положение>
```

Примеры:

```text
//ol 46 0 na
//ol glass shadow a
```

Обозначения положения:

- `na` — обычный активный блок на переднем плане;
- `a` — неактивный блок на заднем плане.

Для стен:

```text
//outlinewall <стена> [краска]
//olw <стена> [краска]
```

## Изменение биома и травы

```text
//biome <исходный биом> <новый биом>
```

Доступные названия:

`Forest`, `Desert`, `Snow`, `Jungle`, `Mushroom`, `Corruption`, `Crimson`, `Hallow`, `Hell`.

```text
//biome corruption forest
//biome crimson hallow
```

Изменение травы:

```text
//setgrass <тип травы>
//sg <тип травы>
```

Очистка растений, лиан и колючек:

```text
//mow
```

## Ремонт интерактивных объектов

После грубой вставки или удаления тайлов сундук, манекен или табличка иногда теряет связь между видимыми блоками и серверной сущностью.

```text
//activate <тип объекта>
```

Поддерживаемые типы включают:

- `chest` — сундуки;
- `sign` — таблички;
- `sensor` — логические сенсоры;
- `itemframe` — рамки;
- `weaponrack` — оружейные стойки;
- `dummy` — манекены-мишени;
- `pylon` — пилоны;
- `mannequin`, `hatrack`, `foodplates`;
- `all` — все поддерживаемые объекты.

```text
//activate all
```

Служебные команды очистки:

```text
//killempty <signs|chests|all>
//fixghosts
//fixgrass
//fixhalves
//fixslope
```

- `//killempty` удаляет сущности у пустых интерактивных объектов;
- `//fixghosts` убирает сущности, у которых больше нет соответствующих тайлов;
- остальные команды исправляют некорректную траву, полублоки и склоны.

## Логические условия

Условия позволяют применять команду только к определённым элементам выделения.

Общий синтаксис:

```text
//команда => <тип объекта> = <значение>
```

Основные обозначения:

| Код | Объект |
|---|---|
| `t` | тайл |
| `w` | стена |
| `a` | неактивный блок |
| `na` | активный блок |
| `tp` | краска тайла |
| `ntp` | непокрашенный тайл |
| `wp` | краска стены |
| `nwp` | непокрашенная стена |
| `wire1`…`wire4` | провода по цветам |
| `ac` | активатор |
| `nac` | отсутствие активатора |
| `li` | любая жидкость |
| `lw`, `ll`, `lh`, `ls` | вода, лава, мёд, шиммер |
| `slope` | форма склона |

Простые примеры:

```text
//set 1 => w = 4
//setwall glass => w
//ol 147 0 on => t = sand
```

Первая команда устанавливает камень только там, где присутствует деревянная стена.

## Логические операторы

| Оператор | Значение |
|---|---|
| `!` | НЕ |
| `&` | И |
| `|` | ИЛИ |
| `^` | исключающее ИЛИ |
| `( )` | группировка выражений |

### НЕ

```text
//set 1 => !w = 4
```

Камень будет установлен только там, где **нет** деревянной стены.

### И

```text
//paw white => t = 2 & w = 4
```

Стена покрасится только в клетках, где одновременно есть нужный тайл и стена.

### ИЛИ

```text
//ia on => t = glass | t = snow
```

Команда затронет стекло или снег.

<div class="guide-note">
  <strong>Два значения одного типа</strong>
  <p>Для выбора нескольких ID тайлов используй ИЛИ. Выражение <code>t = snow & t = wood</code> невозможно: одна клетка не может одновременно содержать два разных тайла.</p>
</div>

### Исключающее ИЛИ

```text
//set 46 => t = 1 ^ w = 1
```

Команда выполняется, когда истинно ровно одно из двух условий.

## Команды администрации

Некоторые установки сервера и действия над другими игроками требуют административных прав:

```text
//worldedit
//magicwand <условие>
//undo <имя игрока> [количество]
```

`//magicwand` выделяет связанные тайлы или стены по обязательному логическому условию. В исходном руководстве указан лимит 10 000 блоков, но фактическое значение может зависеть от текущей конфигурации сервера.
